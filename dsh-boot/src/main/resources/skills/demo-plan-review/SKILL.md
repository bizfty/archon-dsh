# 规划评审

当计划提交（exit_plan_mode）前，按以下清单检查：

## 检查项

1. **目标覆盖**：计划是否覆盖用户请求的所有子目标？
2. **依赖清晰**：步骤之间是否有未声明的先后依赖？
3. **可执行性**：每步是否有明确的验收标准？
4. **风险标注**：高风险的步骤是否被显式标出？

## 输出

给出 通过/需修改 结论；需修改时列出具体缺项。
